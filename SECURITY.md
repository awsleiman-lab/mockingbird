# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository to report suspected security vulnerabilities. Do **not** open a public GitHub issue or pull request for a vulnerability.

Include a clear description, affected versions or commits, reproduction steps or a proof of concept, and any suggested mitigation. We will review the report privately and coordinate disclosure and a fix when appropriate.

## Supported versions

Security fixes are generally considered for the current development version on `main` and the latest released version. Older releases may not receive fixes.
